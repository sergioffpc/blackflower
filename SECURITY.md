# Security Policy

## Supported versions

Blackflower is in early development. Only the latest revision of the `main`
branch receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's private vulnerability reporting form under the GitHub
Security tab. Include:

- the affected revision or version;
- the conditions required to reproduce the issue;
- the expected and observed behavior;
- the potential impact;
- a minimal reproduction or proof of concept, when safe to provide.

Avoid accessing data that you do not own, disrupting services, or sharing the
report publicly before a fix is available. The project maintainer will use the
private report to coordinate validation, remediation, and disclosure.
