# Triage labels

Use these labels whenever a skill refers to a canonical triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Awaiting evaluation. |
| needs-info | needs-info | More information is required. |
| ready-for-agent | ready-for-agent | Specified sufficiently for agent implementation. |
| ready-for-human | ready-for-human | Requires human implementation. |
| wontfix | wontfix | Will not be implemented. |

Readiness labels do not override blocking dependencies; start a ticket only after its blockers are resolved.
